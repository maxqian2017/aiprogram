# 科学计算器 (Scientific Calculator)

一个使用 Python 和 Tkinter 构建的功能丰富的科学计算器图形界面应用程序。

## 功能特点

### 基本运算
- 加法、减法、乘法、除法
- 小数运算
- 正负号切换

### 科学计算功能
- **三角函数**: sin, cos, tan 及其反函数 asin, acos, atan
- **对数运算**: log (以 10 为底), ln (自然对数)
- **幂运算**: x², xʸ, √ (平方根)
- **阶乘**: n!
- **常数**: π (圆周率), e (自然常数)
- **其他**: mod (取模), EXP (科学计数法), 1/x (倒数)

### 用户界面
- 现代化深色主题设计
- 清晰的表达式和历史显示
- 彩色按钮区分不同功能类型
- 响应式布局

## 系统要求

- Python 3.6+
- Tkinter (通常随 Python 一起安装)

## 安装与运行

1. 克隆或下载本项目到本地
2. 确保已安装 Python 3
3. 运行计算器:

```bash
python calculator.py
```

## 使用说明

### 按钮颜色说明
- 🟤 **白色按钮**: 数字输入 (0-9)
- 🔵 **蓝色按钮**: 运算符 (+, -, *, /, ., etc.)
- 🟣 **紫色按钮**: 科学计算功能 (sin, cos, log, etc.)
- 🔴 **红色按钮**: 清除功能 (C, ⌫)
- 🟢 **绿色按钮**: 等于号 (=)

### 操作示例
1. **基本计算**: 点击 `7` `+` `8` `=` 得到结果 15
2. **三角函数**: 输入 `30` 点击 `sin` 计算 sin(30°)
3. **平方根**: 输入 `16` 点击 `√` 得到结果 4
4. **阶乘**: 输入 `5` 点击 `n!` 得到结果 120
5. **科学计数法**: 输入 `1` `EXP` `3` 表示 1×10³

## 技术实现

- **GUI 框架**: Tkinter

- **架构模式**: 面向对象编程 (OOP)

## 注意事项

- 角度模式默认为角度制 (度)
- 某些运算有定义域限制 (如对数需要正数，阶乘需要非负整数)
- 结果最多保留 10 位小数
